# DRin 0.3.0

The first public release of DRin!

DRin is a package manager project designed specifically for Ubuntu.

## Features
- Install packages
- Remove packages
- Search packages
- View package information
- Update package lists
- Upgrade packages
- Clean package cache
- Adaptive parallel downloader
- Verbose mode

## Installation

Download the `.deb` installer from the Assets section and run:

```bash
sudo apt install ./drin_0.3.0_amd64.deb
```

## Requirements
- Ubuntu (Or any Debian-based Distro)
- APT
- Rust is not required for binary installation
